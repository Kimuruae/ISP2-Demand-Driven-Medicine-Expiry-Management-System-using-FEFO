About the project

Kenya's medicine expiry rate is roughly six times the global average, costing the public health system an estimated KSh 9.5 billion a year. This system is a final-year Information Systems project at Strathmore University that demonstrates how integrating First-Expiry, First-Out dispensing with demand-driven procurement can close that gap.
